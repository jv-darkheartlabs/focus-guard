THE BOUNDARY

A threshold, not a rate limit.

Each request is evaluated independently using its attempt-count header. Sending many requests with attempt 1 does not accumulate into a throttle. With threshold 3, attempts 1 and 2 pass; attempt 3 and higher are throttled.

THE DEFAULT

Invalid input becomes 1.

The Rust module trims surrounding whitespace and parses an unsigned 32-bit integer. Missing, empty, zero, negative, malformed or overflowing values fall back to 1. A leading plus sign is accepted.

Passes show a fictional upstream status of 200. Throttles use the module’s default local status of 429. The native module also supports configuration and optional asynchronous TARS callouts outside this simulator. A browser demonstration does not verify a running proxy or its ABI compatibility.
